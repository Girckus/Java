# Java - Swing

This repository contains a **comprehensive and practical collection of examples for Java Swing**, covering **GUI components, containers, layouts, tables, dialogs, menus, event handling, file operations, progress indicators, and other features available in the Swing API**.

The goal is to serve as a **study guide, quick reference, and long-term knowledge base** for developers learning or reviewing **Java Swing and desktop GUI development**.

Each example focuses on **specific Swing components or concepts**, providing practical and executable demonstrations that can be explored independently.

## Project Goals

- Provide a **practical guide to the Java Swing API**
- Demonstrate the main **Swing components and containers**
- Explore different **layout managers**
- Demonstrate **event handling and user interaction**
- Work with components such as **tables, dialogs, menus, buttons, text fields, and progress bars**
- Demonstrate **file loading and other common desktop application operations**
- Provide examples that can be used as a **quick reference**
- Serve as a **long-term personal knowledge base** for Java desktop development

## Requirements

- **Java 17+** (recommended **Java 21 or 23**)
- No external libraries required

## How to Compile and Run

Open a terminal and navigate to the folder containing the `.java` file:

```bash
javac FileName.java
java FileName
```

Alternatively, use an IDE to open the project and run any class containing a `main` method.

## Project Structure

The project is organized into examples and supporting resources used to demonstrate different aspects of Java Swing:

- **`demos/`** — Examples and demonstrations of Swing components and features
- **`data/`** — Data and resources used by some examples
- **`JavaSwing.java`** — Main examples demonstrating Swing components and functionality
- **`PessoaTable.java`** — Example involving data presentation using a Swing table
- **`FileLoadProgressBar.java`** — Example demonstrating file loading with a progress bar
- **`bio.txt`** — Sample data used by the examples

The examples in this repository cover concepts such as:
